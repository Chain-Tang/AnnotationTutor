# Tutor 桌面核心工程优化实施记录

本次按已确认的桌面核心计划实施。分支为 `codex/engineering-performance-20261016`；此前未提交的第三轮改动先固定为 `ba52e36`，没有删除历史 QA、绘图研究或恢复资料。以下结果是可重复的自动回归证据，不代表真实设备的界面耗时承诺。

## 画板与编辑器

- 同一绘制、命中检查使用只读文档和对象／图层索引；事务、保存、导出及外部快照继续深复制。
- 每批复用 source、slot、矩阵、裁剪区域和资源查找。`prepareBoardCanvas` 保持原对象顺序及每个对象的变换、裁剪和混合方式。
- 多选手势开始时按 surface 建立排序吸附坐标，移动二分查询；保留五单位边界、最近距离和原候选并列顺序。缩放限制每个事件计算一次。
- 高亮、边栏及表格共享文档身份和 anchor 定位内容版本对应的计划。滚动、光标和样式只更新表现；内容、anchor 或顺序变化使计划失效。
- `BoardEditorBridge.getStatus()` 返回轻量状态；原 `get()` 的保存快照仍独立复制 anchors。

性能回归检查：1000 对象命中不调用复制用 document getter；同批每个 source 矩阵／区域只测量一次。5000 对象、100 选中对象的吸附查询采用二分读取预算；与旧扫描算法做确定性随机对照。万行文档滚动及光标变化不重新读取全文定位。

## 文库与刷新

- 每个 kind／path 缓存原始内容、指纹、解析结果和诊断，场景同步及文库构建共用。
- 变更按路径读取；删除、重命名、根目录切换清理失效项。显式完整重建仍重读源并修复派生输出。
- `GenerationRefreshQueue` 同批合并刷新需求；执行期间的请求进入后续轮次。完整重建、通知和路径需求合并，每个调用者等待覆盖自身请求的结果。
- 输出写入全部结束后才推进源缓存；失败保持脏路径供重试。损坏源的 last-valid 回退、内部快照和 UI 快照互相隔离。
- 表格 anchor 迁移通过 source 索引查询。学习卡片的展示刷新共用同一代际队列，授权、保护状态及完整性检查仍读取最新记录。

性能回归检查：1000 cells／500 scenes 预热后同步及刷新为零 Markdown 解析、零源文件读取；同批十次刷新一次构建／发布。覆盖在途变更、失败重试、完整修复、无效文件、根目录切换、回退引用隔离及刷新结束微任务窗口。

## 设置与列表

- 普通文本／数字设置统一在失焦或 Enter 提交；标准化后同值跳过。失败保留草稿、标记错误并允许重试。凭据及授权撤回继续走原有即时失效和持久化屏障。
- 多字段 flush 顺序执行，首失败短路；普通字段将赋值、保存、回滚整体串行化，避免一次失败和后续成功交错造成内存／磁盘不一致。路由失败恢复下拉框及绑定代际。
- 普通设置更新聊天模型标记及受影响控件，保留消息 DOM、输入、选区和滚动；语言切换重新翻译，通用布局刷新及会话切换保留原完整刷新语义。
- annotations、cells、scenes 每页 100 条，搜索与筛选覆盖全部记录。各列表在内存保留筛选及页码；筛选回首页，删除、归档及快照更换后校正页码。
- 列表更新保留工具栏及中文输入法组合状态。标签与筛选目录按 snapshot 更新；大量选项在脱离实时 select 的分组中构建。

性能回归检查：三类各一万条记录，最多生成 100 组记录 DOM，仍可搜到最后一条；普通连续输入二十次只提交一次，未修改失焦零保存。1000 条聊天历史经过普通设置刷新后保留节点身份、焦点、选区和滚动；流式回复不会重复插入。

## 翻译及代码维护

- controller 级 FIFO 统一 live、probe 和后台请求；API 上限 2，ACP 上限 1。取消中的旧传输直到实际结束才释放许可。
- `captureText` 接收可选 `AbortSignal`。设置、源文件变更及 controller `dispose()` 取消任务；晚结果不能发布到文档、词典缓存或 UI。
- 词典预计算大小写、长度及词界，按首个小写 UTF-16 单元分桶，保留最长匹配和重复词优先级。
- 修正 memoryRoot 非字符串迁移、独立默认映射对象和缺失翻译键。共享 AST 审计检查实际合并后的四语言词典、占位符及已导入 `t` 的字面量调用；动态键仍由词典一致性与功能回归覆盖。
- 删除经编译器及引用检查确认不可达的动画／控件／导入；题库通用工厂保留参数签名，只标明有意未使用的参数。新增 `tsconfig.production.json`，生产源码启用 `noUnusedLocals`／`noUnusedParameters`，原测试目录不作为本次清理目标。

性能回归检查：四文档并发满足总上限 2／1；包含忽略 abort 的 provider、路由降并发、卸载期间 process 回调及晚响应。词典随机对照覆盖 Latin、CJK、代理对和大小写扩张；一万词条对一万无匹配字符只做一次全文 lowercase、零候选 startsWith。

## 验证方式

```sh
pnpm typecheck
pnpm test:coverage
pnpm test:release
pnpm package
pnpm package:verify
```

`typecheck` 同时检查插件、生产源码未使用代码、浏览器扩展、构建脚本语法及 i18n。覆盖率继续使用原全局及关键文件门槛。发布回归保持 33 项；package 构建桌面／移动兼容 bundle 和扩展，verify 检查封包内容、路径、依赖及 staged release 一致性。GitHub Actions 对 Ubuntu、Windows、macOS 执行相同检查并上传平台制品。

操作次数是性能门禁。大型 DOM／文库测试的超时仅作为 CI 执行预算，不用作用户界面性能指标；耗时需在固定设备和真实 Vault 中另行测量。
