# 灵感画板

灵感画板在桌面 Obsidian 的 Markdown **实时预览、源码模式、阅读视图**和 PDF 上增加透明绘图层。同一文档的三种 Markdown 视图共用画板，可以先独立画、写字、擦除和调整对象，再让 Tutor 根据当前正文与笔迹写手写问题、接画、画教学示意或添加小表情。正文与画板分别保存，画板内容位于配置的学习记忆目录。

## 使用方法

桌面版保存前会在插件的本地状态目录封存未保存草稿及其依赖素材。保存失败后，重新打开同一来源可以恢复笔迹与稳定对象 ID，并显示“已恢复未保存画作”；保存成功后清除恢复标记。恢复内容可一次撤销至保存基线。磁盘或素材已被外部修改时不自动覆盖，保留冲突版本供核对。备份损坏、版本不支持、依赖缺失或超过 64 MiB 时不能承诺完整恢复；权威保存与备份都失败时请保留当前视图，升级流程会阻止自动卸载。回退仅替换程序，不删除草稿；旧版本不会读取新的恢复记录。派生 SVG／瓦片可重建，不承担原墨保存责任。此机制不保证来不及提交的每个输入事件都能在断电或强杀进程后恢复。

新版保存不再原地改写已发布的笔迹包。笔迹增减时先写独立的新包，再提交画板清单；未变化的包继续引用。保存过程中出现外部提交时保留双方版本，冲突稿有独立包引用。原墨、对象 ID 和 v5 几何格式不变，旧包按需继续读取。历史及失败写入的包暂时保留，可能增加磁盘占用；不要手动清理仍被画板、上一修订或冲突稿引用的包。真实宿主恢复与回退的验收范围见下方商业化验证记录。

收到当前原墨或笔迹包的外部变更通知后，保存会重新核对该文件，并为本地内容保留冲突稿和恢复记录。共享原墨的已打开画板都会受保护，未引用的旧包不影响当前画作。恢复冲突稿后的继续修改仍沿用原分支的基线；不会把磁盘上的另一分支当成自己的撤销基线。这依赖宿主文件事件及已知引用，不是对无通知写入的全磁盘监控。确认并处理冲突后再继续保存，不要删除恢复记录来掩盖未保存内容。

当前草稿记录损坏且上一记录可验证时，会先在同一私有目录保留损坏原件，再核对并恢复记录，使恢复后的新编辑仍可备份。外部修复已改变文件、未知版本、无有效备份或超过大小限制时不会强行替换。每个目标最多保留三份不同的损坏原件；达到上限后停止自动修复并保留现状，不自动删除旧记录。这些恢复文件不进入插件发布包。合法的旧笔迹 ID 即使与 JavaScript 内置属性同名也仍可保存，不改写或重新编号。

桌面版首次打开来源时，会在插件私有状态中原子认领同一画板身份。两个窗口或本机进程不得分别创建两份默认作品；过期保存仍按原版本核对，冲突内容另行保留。历史上已存在多份同来源画作时，显式打开画板会列出版本供选择；选择只改变私有入口，不合并、删除或重写另一份作品。取消选择不修改文件。其他版本之后被外部修改，会要求重新核对选择。请先打开带有待恢复内容的版本，不要通过换版本丢弃未保存成果。

选择过历史画作后，可从现有「画板选项 → 打开已保存画板」再次选择；Studio 使用现有「更多创作工具 → 选择要打开的画作」。切换前先结束当前有效笔迹并确认保存，保存失败时保留当前场景和原墨，不继续切换。相同来源的已打开视图一同切换，旧 Tutor 请求和工具句柄失效；文档共画会暂停，可按需要重新开启。取消选择保留当前场景和撤销历史；选择已提交后才关闭对话框时会准确提示选择已保存。切换不同作品后，原来的作品保留在原文件中，不把两份撤销栈或笔迹混为一个作品。

版本缩略图使用派生布局，把不同段落或页面分别排列，不改写画板局部坐标。超过 1000 个对象或总计 50000 个原墨采样点时略过缩略图，说明原因，并允许打开已校验的完整版本。缩略图用于辨认作品，最终字体、栅格图层与材质以打开后的实际画面为准；真实窗口和复杂图层效果仍需按验证报告验收。

来源身份记录只保存来源、ID、修订和分支指纹，不保存正文或笔迹。记录损坏、格式未知，或已确认的画作主文件和备份均缺失且没有完整恢复副本时，不创建新的空画板掩盖问题。身份存储不可用时不能安全创建首份画作；保留当前视图并检查状态目录。旧程序不执行这套来源排他约束；不得在未保存、迁移或冲突未处理时混用旧版。几何、原墨与角色格式不变，私有记录不会进入安装包。这些保护不等于目录重命名、断电或真实宿主多窗口验收已经通过。

1. 打开 Markdown 或 PDF，点击文档标题栏的画笔按钮，或在命令面板执行 **灵感画板 / Inspiration board**。也可以在右侧「提问」模式直接要求 Tutor 作画：先由当前模型做语义判断，再为当前文档打开画板并执行一次绘图；不需要预先打开画板或「一起画」。
2. 文档左侧的竖向工具条使用统一 SVG 图标，悬停可查看名称，选中工具会高亮。选择「画笔」直接画；「橡皮」删除碰到的整个对象。「选择」支持点击、按住 Shift 多选、框选、拖动和通过角部手柄缩放。
3. 「文字」用于在点击的位置写字；「箭头」「矩形」「椭圆」通过拖动创建。点击竖栏底部的颜色圆点展开属性区，可调整手写/普通字体、字号和颜色；图形可切换手绘/规整样式。手绘线条在滚动、重开和导出时保持一致，原始学生笔迹不重新生成。
4. 在「选择」或「文字」工具下双击文字可继续编辑。**回车换行，Ctrl/Cmd+回车完成，Esc 取消本次文字修改**；点击别处也会完成编辑。输入框内的撤销、选字和退格保持原有文本行为。
5. 用「撤销 / 重做」调整画板操作。Tutor 一次回应可整体撤销；正文编辑有独立的撤销历史。「更多工具」包含删除、组合/解组、形象、保存表情、画板选项和隐藏画板。
6. 在 Markdown 编辑视图选择「编辑正文」即可继续输入与选字；阅读视图和 PDF 对应「阅读」。选择绘图工具后，覆盖层接管文档区域的指针。中文输入法候选尚未确认时，先完成输入再切换绘图或分享画板。
7. 「隐藏画板」只关闭当前视图的显示；再次打开可继续编辑。在「画板选项」中点击「打开已保存画板」，可查看 Markdown 入口、可编辑 JSON 和 SVG 预览。不同段落或页面的预览会依次排列。

Markdown 绘图使用稳定段落锚点，正文插入、换行、文字撤销和视图切换时保持画作身份与形状。折叠段落或滚出视野只隐藏显示层；原段落被删除或无法可靠匹配时，画作仍保留，可定位到目标段落后使用「在此恢复未定位的画作」。源码中的图片链接按源码区域定位，不按渲染图片尺寸定位。PDF 使用页面坐标，页面重新加载、缩放或旋转时不会改写原始笔迹。

画板获得键盘焦点时，可用 **V** 选择、**P** 画笔、**E** 橡皮、**T** 文字、**A** 箭头、**R** 矩形、**O** 椭圆；**Esc** 返回正文交互。这些工具快捷键不接管正文或文本框中的输入。

重命名已关联来源时，文档画板与 Studio 保留原画板、对象、笔迹 ID 和撤销/重做历史。迁移会短暂暂停输入并取消旧的共画请求，先在私有恢复目录核对新路径下的完整场景与依赖，再切换来源。主文件保存仍失败时显示待恢复状态，不能当作正式保存完成；恢复目录也无法写入或目标已有另一幅画作时，保留原场景并报告失败，不另建空白画板替代。连续重命名按顺序处理，失败后先修复前一次迁移。该路径已覆盖合成自动化和私有文件系统测试，真实 Obsidian 文件事件、系统中断及跨设备流程仍待验收；不要用这些测试成绩推断完整数据可靠性已通过。

同一来源有多份历史画作时，当前版本暂不自动迁移全部作品，会在写入新恢复路径或退休原路径前明确拒绝，原作品与恢复稿保持可编辑。直接草稿迁移和中断后继续迁移也检查这一条件；若准备过程中新增历史分支，保留原路径和完整准备稿，不把一份作品迁走后遗漏其他作品。宿主已经完成的文件重命名不会被插件自动撤销，需先处理来源冲突再继续；历史全部版本迁移仍属未完成能力。

## 手写字体与安装

手写文字采用 Excalifont 与中文 Xiaolai 字体组合，按实际字宽换行，不横向压缩字形。字体随插件离线分发，按当前实际文字在所属窗口加载，不再等全部 216 个字体子集才允许开始画。字体就绪后会修正文字的派生高度，包括对应撤销/重做状态，不新增撤销步骤。截图等待字体加载，SVG 预览只嵌入所需字体分片。字体来源和 SIL Open Font License 见插件的 `assets/fonts/` 目录；相关实现参考 [Excalidraw 字体资源](https://github.com/excalidraw/excalidraw/tree/master/packages/excalidraw/fonts)。

**安装本轮版本时必须保留 `assets/fonts/`。** 完整插件 ZIP 和 `pnpm install:vault` / `pnpm install:dev-plugin` 脚本均包含该目录；手动仅复制 `main.js`、`manifest.json`、`styles.css` 不足以安装手写字体。应将这三个文件与同版本 `assets/fonts/` 一起放入 Vault 的 `.obsidian/plugins/annotation-tutor-lite/`，再重载插件。字体文件缺失时需从完整安装包补齐。

## 和 Tutor 一起画

- 点击「一起画」后，停笔或正文编辑停顿约 1 秒会合并变化；自动请求间隔至少 3 秒，同时最多处理一个请求。未保存的正文修改也会更新观察版本，中文组合输入期间不截图。同文档分栏使用最近交互且已开启共画的视图提交，避免重复请求。
- 直接在右侧 Tutor 对话中提问、要求接画、修改示意图或发送表情；「问我一个问题」「画个示意」「来个表情」快捷指令也在右侧。明确要求画图时会进行一次视觉请求，**不会自动开启持续共画**。开启「一起画」后，普通问答也会结合当前画板。明确修改正文、Build/Plan 模式及已固定批注继续走原有正文对话。
- 自动打开前的语义识别使用当前连接和模型，不读取截图、不允许模型调用工具；识别失败、取消或换文档时不继续开板。提到绘画、讨论画派、否定绘图或要求修改正文，不会仅因关键词而开板。首次 OpenCode 识别需要启动隔离会话，仍有模型与启动等待时间。
- 关闭右侧后，同一轮回复继续在画板的临时手写气泡中显示。新回复替换前一条气泡；学生笔迹、问题和示意图保留。气泡可拖动，「留在画板」将回复存为可编辑、可撤销的文字。完整聊天记录始终在右侧。
- 画板打开时可执行命令 **在画板上快速输入 / Quick message on the board**，或在文档区域按 **Ctrl/Cmd+Alt+L** 呼出临时输入条；回车发送、Esc 关闭。输入法候选未确认时回车不会发送。原有 **Ctrl/Cmd+Shift+L** 仍用于添加学习批注。
- Tutor 接收当前可见原文与画板的截图、附近文字和对象摘要。截图排除竖栏、临时回复/输入和选择控件；画面之外的文档内容不会因开启画板而被全量截图。
- 「暂停」、隐藏画板、切换页面或模型会使原请求失效。暂停后仍可本地绘图，迟到的结果不会落到页面上。Tutor 的绘图不会自行触发下一轮请求。

画板与右侧 Tutor **共用聊天引擎、模型、API 地址、密钥和对话记录**。旧版画板独立模型字段仍可读取，但不再用于选择模型，也不再提供独立设置入口。视觉请求仍要求模型支持图像；OpenCode 会检查图像能力和模型选择，不能以文字请求冒充视觉共画。普通聊天保留已有的阅读、批注与正文编辑功能。

Direct API 使用可取消的 SSE；OpenCode 使用 ACP 消息增量并复用暖会话。文字按接收到的短语显示，图形逐对象出现，路径支持逐段延伸。即时问答与画板使用官方 DeepSeek 时会启用快速回复（关闭 thinking）；规划和正文修改保留默认行为，第三方连接不附加 DeepSeek 专属参数。该参数依据 [DeepSeek Thinking Mode 文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

Tutor 输出路径、箭头、矩形、椭圆、文字、版本化角色和表情素材。新问题默认使用可编辑的手写文字；流程、关系、对比和基础物理示意由图形与短标签组合。相关对象默认成组，学生可整体移动、缩放，也可在「更多工具」中解组后单独修改。图形组合与撤销单位独立，一次 Tutor 回应仍然整体撤销。

基础函数和有限点极限图由宿主统一计算曲线、点、轴和辅助线。新图的坐标标签会根据实际线段、箭头头部及其他文字选择位置，避免仅因整条曲线的外包矩形而过度避让；位置选择可重复，保存和导出后不重新随机排列。空间极小或标签密集时仍可能无法完全避开，学生可以移动文字。这个布局改进只影响新生成的图，不自动重排历史画作；数值关系检查不等于数学证明。当前候选包的实测范围和未通过项见 [商业化优化验证记录](qa/commercial-optimization-20261009/report.md)。

在已有作品上添加笔迹、文字或形状时，新批注沿用作品的段落锚点；组合示意图内部的空白也使用该组合的锚点。这样正文块间距改变或切换 Markdown 模式时，批注与作品仍使用同一坐标来源。批注保留自己的对象和撤销单位，不改写原图或自动合并分组。作品之外的笔迹继续绑定附近段落。锁定参考图时，应在未锁定的绘图层上批注；隐藏作品不参与定位。已有批注的锚点不自动迁移，不承诺批注随原图单独拖动、缩放或旋转联动。

新图放置时为正文预留间距。已保存的图在视图切换或正文重排后，只有绘制边界实际与正文相交才隐藏；仅预留间距变窄不会要求重新安排位置。编辑器中的空行不算正文障碍，含文字、媒体或控件的行继续受保护。真实遮挡仍保留原始数据，恢复空白后重新显示，不自动移动作品或批注。

未选择已有对象时，新数学图优先绑定绘图区上方最近的可见段落，截图、模型坐标与最终图形使用同一锚点，减少阅读、源码和实时预览之间累积段落间距造成的遮挡。已有图的锚点不自动改变；媒体尺寸或正文内容变化造成的真实遮挡仍会提示处理。

流式图形先显示在临时预览层；每个事件校验字段、坐标、资产及权限，整轮正常结束并通过最终校验后才一起保存。取消、断流、非法或过期响应会清除未提交预览；不会保存半截 SVG，也不会直接执行模型提供的 SVG/HTML。图形由插件的可编辑对象渲染为 SVG。学生可以修改双方对象；Tutor 只能修改自己的、尚未由学生改动的对象。没有值得补充的内容时，Tutor 可以不新增对象。不再在整包完成后追加逐对象播放的等待，撤销或停止后旧流不会恢复对象。

模型输出的非负极细线宽（小于 0.5 像素，包括 0）会归一到最小线宽。坐标越界或图形字段错误最多请求模型纠正一次，清除前次临时预览后重新校验；仍不通过则显示可读的失败提示，不保存半幅画。身份、作者权限、资产引用、网络和供应商内容拒绝不走这类自动纠正。

水彩等材质的手动绘制按显示帧合并预览更新，并在一笔进行期间缓存已完成的画面；原始压力和笔迹采样仍保留。长笔迹本身仍需渲染，实际速度取决于笔迹长度、窗口像素数和设备。

如果当前窗口无法截图、模型不支持图像或请求失败，共画会暂停并显示原因，本地绘图仍然可用。

同一窗口中的视觉截图串行执行，各自完成后才恢复被隐藏的工具条和私有关怀界面；独立窗口可以分别截图。截图等待或原生捕获超时、来源视图关闭、等待期间正文改变，以及捕获期间出现新的私有关怀区域时，丢弃本次画面，不使用晚到像素继续作画。C60 候选将可靠锚定的独立图放在临时画图区内，正文换行不会再令整组图隐藏；宽图保持尺寸、局部横向浏览。尚未可靠关联或用户手动摆放的旧作品继续使用原布局，桌面完整交互以验收报告为准。

## Tutor 形象

打开「形象」可选择两套原创预设：**圆团小伙伴**、**书页小精灵**。每套支持思考、疑惑、发现、加油、庆祝、安静陪读六种表情。

- **上传**：选择 PNG、JPEG 或 WebP，单个文件不超过 8 MB；原图保持独立保存。表情通过文字、配件及原图组合表达。
- **共创**：选中满意的学生与 Tutor 绘图，点击「将选中内容存为形象」并命名。可将后续修改存为同名形象的新版本。
- **版本**：形象列表可以选择已保存的历史版本。画板对象引用具体形象版本，更换或更新形象不会改变历史画作。共创形象继续引用原始笔迹和已有资产。

## 表情素材

工具条的「表情素材」打开带缩略图和搜索的素材面板，包含颜文字、两套原创角色的六种表情、上传图片和双方共创素材。点击即可将素材放入当前区域，随后可移动、缩放或删除；**插入表情不改变当前 Tutor 角色**。

- 用「上传表情」添加 PNG、JPEG 或 WebP，原图独立保存。
- 选中双方画作，在素材面板或「更多工具」中选择「将选中内容存为表情」，命名后可再次使用；同名更新保存为新版本。
- Tutor 可引用允许使用的素材，也可用颜文字、线条和基础图形创作简笔表情；历史画板始终引用原来的素材版本。
- 卡片右上角可将表情从个人素材库移除，操作后可立即撤销；「已移除」筛选可以日后恢复。内置角色的六种表情可逐张隐藏，自定义素材按整个素材移除。资源文件与旧画作引用不会被删除。

个性化 Tutor 形象及衍生表情的设计和隐私门槛见 [Tutor 个性化形象与表情包规范](tutor-avatar-expression-spec.md)。

本轮不接入新的位图生成服务。Pad 手写识别和多人联网协作仍留待后续。

## 保存与恢复

以下路径均位于配置的 `memoryRoot` 下，默认是 `Agent Memory`：

```text
boards/BOARD-….md                 Markdown 入口
boards/BOARD-….board.json         可编辑画板
boards/BOARD-….previous.board.json 上一个有效版本
boards/BOARD-….v1.board.json       首次升级时保留的 v1 原始画板
boards/BOARD-….svg                可重新生成的预览
ink/INK-….ink.json                稳定 ID 的原始笔迹
ink/INK-….svg                     原墨预览
characters/CHAR-….v1.character.json 版本化形象或表情素材
characters/CHAR-….png             上传原图，也支持 JPEG/WebP
```

画板格式升级为 v2，仍可读取 v1。旧画板首次保存时会先将原文件保留为 `.v1.board.json`，再写入 v2；不会批量重写旧对象样式、原始笔迹 ID 或历史形象版本。

保存按顺序执行，先保存笔迹和依赖，再更新画板。排队中的中间状态会合并，临时回复和逐段预览不进入逐字保存；关闭和切换目录仍等待保存完成。移动或缩放对象不会复制、重写原始点列。来源文档重命名后，画板身份保持不变。分栏中的同一文档共享画板状态，关闭一个分栏不关闭另一个。

外部修改与本地版本发生冲突时，会保留外部文件，并将本地版本另存为带 `.conflict-…` 的文件；重新打开画板可载入外部版本。主画板写入中断时，可从上一有效版本恢复。普通磁盘写入失败时，关闭画板或切换存储目录会先重试；仍失败则保留当前画板供继续处理。

切换学习记忆目录前，插件会完成旧目录的保存。画板文件使用独立监听路径，绘图不会触发整个学习记忆库重建。

## 参考图与原生笔触重绘（实验功能，2026-09-16）

在设置的 **AI 图片生成** 中配置 Qwen 或 OpenAI 图片模型，在 Markdown 或 PDF 文档的右侧「提问」模式输入。系统先通过当前聊天模型识别绘图意图与绘制方式，再按需打开来源文档的画板：

> 请先生成参考图，再在画板上画一位可爱的鲸鱼娘角色，吉卜力风格，蓝白色衣服，鲸尾与鳍状发饰，白色背景。

系统会生成一张参考原图，展示原图与可编辑重绘的对照，再由你选择「开始在画板绘制」或「立即完成」。播放中可立即完成或取消；完成后整幅作为一组，可移动、编辑笔触、一次撤销及重做。取消不会保存半幅笔触，已生成的参考原图仍保留。

- 画板上已经写了要求时，先选中该文字对象，再用「更多工具 → 按选中文字绘制」。文档里的任意句子不会因为被截图就自动变成执行指令。
- 「根据文章画角色」会进入画板；明确插入、改写正文仍走原有正文编辑流程。
- 简笔表情、教学示意图和已有图形的改色使用原生图形协议；完整角色插画使用参考图流程。明确说「先生成示意图，再根据示意图调整」也会调用图片生成，花园、场景与抽象构图均可，不再被「示意图」这个词排除。明确说「不要生图，直接修改已有图形」则使用原生协议。
- 图片生成使用已有的图片模型配置，聊天继续使用聊天连接。语义步骤会从最近的用户对话补全「这个图画」的主题、风格与最新修改要求。本流程只发送补全后的绘图描述，不附带论文正文或页面截图；不会把聊天模型支持图像输入误当成支持图片生成。
- Tutor 可以给自己已有的矩形、椭圆和闭合几何路径增加纯色或纹理填充。要求「只填充，不改变位置和边框」时，更新原对象；未指定填充的其他修改保留原填充。材质画笔路径不能作为闭合区域直接填充。
- 原图和生成信息保存在 `memoryRoot/references/`；画板保存原生 path 对象，不依赖原图贴图显示。明确绘图请求返回零操作时会报告失败，不再把一句承诺当作绘图完成。

当前重绘采用色彩区域提取与连续轮廓：先合并相近颜色的小碎片，生成闭合色块，再生成独立的轮廓笔触；保留透明区域与内孔。默认最多 384 像素采样，并限制对象数量，不再把整幅图逐行拆成大量圆头短线。区域内部仍会简化渐变与细节，不能恢复人物语义部件或专业画家的原始笔顺。

### 多画笔与分层上色（2026-09-18）

参考图预览窗口提供「清晰插画」「油画」「蜡笔画」「水彩」四种预设，也能分别选择轮廓画笔、平滑填色/画笔铺色、上色画笔。例如：

> 先生成一张花园参考图，再用铅笔画轮廓，用油画笔铺色。

> 先生成一个角色参考图，用钢笔勾线、蜡笔上色。

自然语言要求通过同一次语义识别传递材质选择，预览时还可修改。切换风格只使用已生成的参考图，不重新调用生图服务；取消后重试保留本次选择。手动画笔菜单也新增了独立的蜡笔。

- 平滑填色使用真正的纯色填充，修正了此前误用纸纹图案的问题。
- 油画、蜡笔、水彩铺色调用现有材质画笔引擎，连续笔触裁切在色块边界内。白底和微小细节采用平滑填充，避免给空白纸面和小点强行添加纹理。
- 色块可以整体移动、改色和修改填充；轮廓是单独的原生笔触。区域内部排线按保存的画笔参数和随机种子确定性重放，暂不拆成可单独选择的每一小段笔触。SVG 导出保留裁切和矢量笔触。
- 播放顺序为色块后轮廓，整幅仍作为一次撤销单位。显示缓存只保存在内存中，保存数据仍是可编辑几何与画笔参数。预览分批生成，取消或切换风格会使旧预览失效。

[本轮风格对比与验证记录](qa/reference-materials-2026-09-18/README.md)。

参考图流程根据文字描述生成新图，再作为一组新笔触加入画板；它不对旧图进行逐像素编辑，也不保证沿用旧图的精确几何布局。需要保留现有图形的位置与尺寸时，请明确要求直接修改已有图形。参考图分流、真实生图及填充协议的验证记录见 [2026-09-16 验证](qa/reference-routing-2026-09-16/README.md)。

### 在画板文字中提出绘图要求

开启「一起画」后，当前可见区域内由学生创建、编辑的文字对象，若以「请你绘制」「请帮我画」「画」等明确绘图要求开头，会作为实际指令发送。先写文字再开启也可触发。右侧会显示具体要求；例如「请你绘制一个二次元的米老鼠」进入参考图流程。正文中的句子、Tutor 自己生成的文字、普通描述不自动执行。这里只识别文字工具输入的文本，不含手写笔迹 OCR。

同一文档打开期间，相同文字对象与文字内容只自动提交一次，移动、调整样式或分栏不会重发。编辑旧文字对象后，按最新文字提交顺序选取请求，不会被后创建的旧请求盖住。失败、取消后可以使用「重试」，不无限自动重试。暂停时不自动提交。

### 失败恢复、参考图复用与部件编辑（2026-09-16）

图片服务的内容拒绝与网络中断分开处理。例如 Qwen 返回 `IPInfringementSuspect` 时，会显示中文原因及「修改要求」，不再提供原样重试，也不会自动替换角色要求。点击「修改要求」将原文填回输入框，由你修改后发送；也可从「更多工具 → 重绘已保存参考图」继续。支持图像输入的聊天模型不会因此变成图片生成模型，不能通过重试解除图片供应商的内容判定。

- 右侧对话显示进行中、已完成、失败或已取消。失败和取消后提供「重试」；关闭右侧时，画板回复也提供此入口。失败提示会覆盖先前的「正在绘制」承诺，未完成的图形仍整组丢弃。
- 重试保留原请求和来源画板，不会画到后来切换的文档。任务状态和重试记录只在本次插件会话内保留；重载插件后，可重新输入要求或使用已保存参考图。
- 参考原图保存成功后，即使取消预览、播放或后续失败，再次重试会直接读取原图并本地重绘，不重新调用图片生成。原图尚未保存时的重试仍可能重新生图。
- 「更多工具 → 重绘已保存参考图」可选择 `memoryRoot/references/` 中保存的图片，无需调用图片生成服务。原图和最初生成信息保留，复用产生的新信息另存。
- 「更多工具 → 人物部件」支持为选中的笔触命名（如眼睛、头发）。完整角色默认成组，先解组，再选中所需笔触并命名；之后可从部件列表重新选中、整体移动、缩放或改色。标签随画板及共创形象保存，复制后部件身份独立。这是手动指定，不是自动语义分割。
- 对象修订未变化时复用绘制快照，避免逐帧复制全量画板。模型上下文最多详列 96 个对象、64,000 字符，并保留对象总量/类型摘要，优先包含文字、人类编辑及最新对象；本地完整数据和权限校验不裁剪。超过摘要范围的具体笔触修改能力有限，可以手动选择编辑。

本轮修复证据及未完成的真实窗口验收见 [任务恢复验证记录](qa/task-recovery-2026-09-16/README.md)。

### 原生示意图的回复完整性（2026-09-18）

「用几何图直观表示极限」等要求通过语义识别进入原生绘图。模型返回箭头或路径时，可兼容保持绝对位置不变的负方向局部偏移；真正超出截图的图形仍会拒绝。模型正常结束却没有完整绘图时，最多自动纠正一次；连接中断、输出长度上限和非法绘图分别显示原因。失败预览不会覆盖已有画作。

这段记录对应 2026-09-18 的旧自由绘图链路：当时真实模型可以完成协议，但极限图的曲线与标记错位，准确性未通过。后续基础函数图已改为宿主统一计算，仍须按具体题目核对。原始失败证据保留在 [极限绘图排查](qa/limit-drawing-2026-09-18/README.md)，当前验证范围见上方商业化优化记录。


## C60 正文内画图区（测试候选）

Markdown 阅读、实时预览和源码模式在关联段落后临时预留图幅；关闭画板即移除，正文文件不会插入空行。宽图保持原尺寸，可在图区横向滚动。同一段落的多幅图分别预留，滚动位置仅属于当前视图。PDF 保留页面坐标。

新图上批注记录其画图区。旧普通笔迹不自动迁移；Tutor 提示后，可同时选中图示与旧批注，通过“更多 → 画板选项”确认关联。关联与后续绘画遵循同一撤销顺序；关联、布局恢复及占位测量不会单独触发自动共画。用户明确手动移动过的旧作品保留原有透明覆盖布局。折叠、删除段落或无法定位时保留画作数据。

正文撤销可能由 Obsidian 表示为整段替换。当前会话保留有界的来源锚点快照，只有整份正文精确恢复到已知版本时才恢复原段落身份，避免重复段落被错误关联；不是模糊匹配，快照不包含关怀数据，也不进入画板撤销栈。超出缓存范围或无法可靠定位时继续保留未定位作品。

布局写入独立 `boards/<boardId>.layout.json`，不更改 v5 原始对象坐标或笔迹 ID。保存中断只恢复与已保存场景完全匹配的布局，外部变更进入冲突处理。可编辑归档包含布局清单；SVG 与作品预览展示完整图幅，不使用当前窗口裁切范围。

视觉请求同时携带布局修订和每个对象到截图的映射；旧对象的摘要标明实际图片边界，修改结果转换回该对象的原始坐标。模型不能提供或替换这些映射，也不能扩大作者权限。截图通路和保存通过不等于模型能准确找到每条笔迹，具体视觉失败样本保留在验证报告中。

文字字号同样按截图比例换算：DPR 2 时，24 个图片像素对应 12 CSS px。新文字的宿主默认字号至少 12 CSS px；模型显式指定更小字号时，在绘图协议校验中允许一次完整纠正，避免误报为“没有绘图区”。未调整字号的历史文字保持原样，文字框仍由宿主测量后换行，不横向压缩。

C59 保留为程序回退基线。降级保留布局清单与新作品，重新升级后恢复；本批只安装 Tutor-Acceptance 测试库。PDF 全矩阵、长期性能及商业发布门仍需独立验收。
