# Learning v3：受限学习证据契约

状态：S1 数据边界候选，2026-10-09。自然对话写入切换与完整续学调度属于 S2，尚未宣告验收完成。

记录独立保存在配置学习目录下的 `learning/v3/episodes/<UUID>.json`。v1/v2 不批量转换；新版共享摘要只投影可从已知题库还原并校验的旧数值或选项。不能可靠还原的旧记录显示为未验证，不复制原回答、反馈、反思或模型生成题面。原文件仍保留在本地。

## 自动记录允许的内容

- 宿主确定的来源、题目、邀请、请求与证据 ID，修订及时间。
- 固定 `limits-v3-1` 题库引用：模板、主题、题池与受限种子。题面、答案及图形由宿主重新计算；同一题目 ID 的引用一经保存不可修改。
- 规范数值或选项序号、确定性判定，以及限定数学判据的 Tutor 判断。Tutor 判断保持未验证，不变成客观掌握分数。
- 提示或答案的准备、呈现、未知状态及对应呈现 ID；准备记录不能通过撤销评分删除。按单调序号判断先后，避免同毫秒事件混淆。
- 引用既有证据的纠正、到期任务与图形／专家关联。旧事件续学只引用身份，不增加一遍完成次数。

自动结构没有任意 `attempt`、`feedback`、`reflection`、`notes` 或扩展自由文本字段。自由解释可在当前对话反馈；S1 暂停自动存原文，界面不声称逐字记住。普通聊天仍沿用用户选择的保存方式。

## 固定容量与保存规则

| 项目 | 上限／规则 |
|---|---|
| 单记录实际 UTF-8 字节 | 512 KiB，包括写盘格式化的空白 |
| 题目 | 100 个；种子 0–1,000,000 |
| 证据／帮助事件 | 分别最多 500 个，ID 与事件序号唯一 |
| 请求回执 | 2,000 个，不自动丢弃以重新接受旧请求 |
| 到期任务／关联 | 分别 100／500 个 |
| 数值 | 有限数，绝对值 ≤ 10¹²；不执行模型表达式或代码 |
| 选项 | 仅题库实际存在的选项，最多 8 个 |
| 保存 | 串行、修订与删除屏障校验、比较写入 |
| 上一修订 | `.previous`，仅来自已验证旧记录 |
| 删除 | 独立 `.deleted` 屏障；晚到保存及旧备份不能复活 |
| 外部修改 | 按来源和记录使上下文失效；冲突不覆盖外部成果 |
| 损坏 | 逐记录隔离；有有效备份才比较恢复，未知新格式不降级 |

字段、引用及实际序列化容量必须在写主文件、备份或其他派生副本前通过。故意提交私人原文或伪造判据的模型动作无法获得自动写入通道。已有损坏文件的保全副本按本地原文件权限管理，这不等同已清除历史私人内容。
