## 本轮实施

### 1. 索引与派生文件：内容不变时跳过写入

此前常规刷新虽然只读取脏源文件，仍每次重写 `index.json` 和最多六份 Markdown 派生文件，更新时间戳还会制造额外 Vault 事件。

现在比较实际渲染内容的指纹，只有内容变化时更新对应产物及时间戳；成功写入后才更新缓存。派生文件事件与目录事件保留代际失效，自己产生的事件通过内容核对清除；即使关闭自动刷新，或 watcher 尚未完成防抖，也不会反复重写相同输出。缓存只保存指纹与时间，不额外常驻六份渲染正文。

确定性回归测得的工作量：

| 场景 | 本轮行为 |
| --- | --- |
| 1,000 cells + 500 scenes，无变化同步及索引刷新 | 0 次 `vault.read/process/modify/create`、0 次 `adapter.write`；仍有 1 次 cache `exists` 检查 |
| 新增一个已有概念的 cell | 2 次源文件读取、1 次 scene process；仅更新 overview、cells 索引和 JSON 缓存 |
| 只修改批注笔记 | 1 次源文件读取；仅更新 overview 和 JSON 缓存 |
| 自写事件尚未被 watcher 核对 | 对受影响页核对指纹，最多六次正文读取；不重复写入，后续安静刷新不再读正文 |

测试覆盖外部替换、删除、目录事件、设置变化、失败重试、根目录切换、刷新中外部更新、指纹读取期间的新代际及高并发指纹淘汰。手动完整重建仍强制修复全部产物，新 Store 也不信任此前的输出缓存。

边界：同一进程内绕过 Vault 事件改写已有输出或私有 JSON 缓存，普通增量刷新可能暂时信任缓存；手动完整重建或重新加载会修复。源资料解析与关系计算仍遍历内存资料，本轮没有把整个刷新变成 O(delta)。

### 2. 画板预览：一次分组，避免复制原始采样

`portableBoardObjects` 供分支预览与保存/导出预览共用：按 anchor 一次分组，取代每个 anchor 再扫描全部对象；只浅复制需要改坐标的对象，不深复制只读的 points 等嵌套数据。旋转包围盒逐对象累计，不再分配全部角点数组并向 `Math.min/max` 展开巨大参数列表。使用 slot/matrix 的预览也直接读取对象数据。

保留对象绘制顺序、anchor 首次出现顺序、旋转几何、最小宽高与原始数据；冻结嵌套数据的渲染回归，以及 40,000 个同 anchor 对象的回归通过。保存恢复、字体准备与 repository 屏障保留。

可复跑微基准：

```bash
node scripts/benchmark-board-portable-layout.mjs
```

脚本从固定基线 `22a7a7a` 抽取旧实现并计入原有 `structuredClone`，与新实现比较。5,000 对象、5,000 anchors、500,000 个采样点，双方预热各两次，交错测量各五次：

| 项目 | 修改前中位数 | 修改后中位数 |
| --- | ---: | ---: |
| portable 预览布局准备 | 778.49 ms | 1.08 ms |

新旧结果严格相等；独立工作量回归确认每个 anchor 只分类一次，布局不遍历原始点数组。这是布局准备的微基准，不代表整个保存或导出的提速比例；真实绘制、字体与磁盘开销不包含在内。运行该比较需要本地保留基线 Git 对象。

### 3. 启动：独立恢复并行，保留就绪屏障

learning、support 与专家结果存储改为同时恢复，全部结束后才注册视图、活动监听与后续服务。凭据迁移、绘图事务及此前的 chat history 屏障继续在前。

任一恢复失败即取消本轮 lifetime、清理 support 过期计时器，同时等待已经启动的 I/O 完成后再抛出原始错误。卸载不会提前销毁凭据，晚结果不会发布任务或注册视图。新增七项生产生命周期回归验证重叠、每项单独阻塞、失败、卸载和计时器清理。

确定性测试证明三项恢复可以重叠；尚未测量真实 Obsidian 冷启动降幅，可通过现有 `startupDiagnostics()` 继续观测。

### 4. 设置页：局部更新与模型绑定修复

高亮颜色模式、画板连接模式只重建相关的 0–2 行，替代通用页四十余行的重建。自动点评及三个无条件依赖区块的学习开关不再触发整页重绘，保留其他输入、焦点、选区与滚动位置。

同时修复原有的画板模型绑定问题：API/OpenCode 引擎切换后，模型输入重新显示并绑定对应设置键，避免继续写入旧引擎字段。已有 custom 和 inherit→custom 两种入口均有往返回归；局部更新回调始终绑定实际挂载的容器。
