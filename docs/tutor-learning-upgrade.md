## 0.5.x 自然对话预览（历史功能说明）

本轮新增体验无需开启旧学习卡。普通提问直接回答；适合练习时 Tutor 会简短邀请并说明保存进度，同意后才创建本次记录。可以自然说“提示一下”“直接告诉我”“先休息”“继续上次的题”。没有增加教学按钮、选择卡或常驻面板。

极限与连续包含六主题、54个版本化题目模板，练习、迁移和延迟题分别选取。答案与帮助程度由宿主记录：看过提示、完整答案或专家解释后，不计为未使用提示完成。自由解释属于可纠正的 Tutor 判断，不产生客观分数。初次完成约一天后检查，通过后约三天、七天再检查；只在相关学习时提及，没有后台催促。每日默认20分钟是近似学习预算，用户可调整或要求继续。

侧栏、批注、画板和授权的外部 Tutor 共用来源可追溯的证据摘要。多个练习无法可靠匹配时，不猜测要继续哪一个；外部新版证据读取需独立授权，旧配对默认不开启。支持对话和关怀摘要不进入此摘要。

学习专家开关仍默认关闭。已开启时，可在对话中要求 Codex 独立核对，Tutor 说明所分享的当前材料并汇总结果。专家不能改学生证据或直接落图。已完成专家产物可重载恢复，中断任务不自动重发模型调用。保存专家结果不等于数学证明或掌握评价。

新记录位于 `memoryRoot/learning/v2/episodes/`，专家结果位于 `learning/v2/expert-tasks/`；旧 v1 文件继续读取，续学通过引用关联，不复制完成次数。程序回退不会删除新记录、笔迹或角色。

本轮安装产物为桌面预览，0.4.6封存包仍作为回退基线。本任务仅安装测试库；收尾核对时，另一个画板性能任务已向正式库部署共享源码的0.5.3，正式库不能再按0.4.6描述，也不能据此认为完整预览包已通过验收。逐批结果、真实模型记录、安装状态及未通过项见 [2026-09-27 验证报告](qa/natural-learning-20260927/report.md)。未完成真实 GUI／输入法／PDF／弹出窗口矩阵及密集操作后性能验收前，不宣称正式通过。

# Tutor 0.4.6：可回退的学习与支持升级

本轮面向大学与成人学习者。原有侧栏、批注、翻译、画板与本地操作继续保留；新学习闭环、主动签到、专家入口分别默认关闭。设置中可独立开启，连接和密钥不迁移到其他供应商。

## 使用

最简单的入口：在 Markdown 阅读/编辑视图或 PDF 中选中文字，右键选择「问 Tutor」。选区会固定在右侧，直接输入问题，也可点击「解释选中内容」或「画个示意」。不要求先创建批注或开启学习闭环；不自动发送，不增加第二个输入框。切换文档不会悄悄换掉这次选区；取消固定后恢复跟随当前页面。原文变化时重新选择后再作图，解释仍可使用已捕获的选区。

Studio 重载会等待场景数据就绪。加载失败会保留文件并提供「重新打开画作」；升级健康检查包含后台 Studio 标签页的就绪状态。

新增教学图会先寻找当前可见页面的空白，避开正文、已有作品和工具条；整组等比放置，文字不会被挤到难以阅读。空间不足时可选择在独立 Studio 作图，取消不改变原作品。PDF 无法可靠判断扫描页面中的空白时，也提供这个选择。明确要求圈线批注时仍可标记原文。

正文重排后，本版自动安排的图示若与正文重叠，会暂时隐藏并显示「图示已避让正文 · 查看」。图形数据不变；空白恢复时自动显示，也可预览后「重新安排到空白处」，这次移动可以一次撤销。0.4.6 将新图落位与后续批注分开：直接在图上写字、圈线、添加文字不会让原图隐藏，无需开启额外模式；新生成的独立图示仍避开作品与笔迹。图形与批注暂不自动绑定，单独移动原图时批注不会自动跟随。详见 [批注兼容修复](qa/board-annotation-20260926/report.md)。此规则不批量改动旧作品，也不接管用户手动摆放的图形。阅读、编辑和分栏共用原画作身份。验证范围与保留项见 [布局验收记录](qa/board-placement-20260926/report.md)。

在设置中开启「学习闭环」，在学习助手侧栏展开「学习 · 极限与连续」。可从当前文档开始，也可从批注进入后开始，学习记录保留批注身份。每次学习包括尝试、可选提示或直接解答、共画、新题验证、反思与延迟检查。每日预算默认20分钟，可调整；超出内容顺延。

首批六个主题：函数值与极限、左右极限、邻域、可去间断、跳跃间断、连续性。数值与选择题由确定规则判定，自由解释标为 Tutor 判断；可在证据列表提出纠正。提示后答对、独立作答、迁移和延迟验证分开记录。旧复习次数仍用于 SM-2，不代表完整概念掌握。

「在独立学习画板共画」创建关联该学习事件的 Studio 教学图，避免大图挡住正文。所有点、曲线和辅助线仍由统一数学计算生成，可编辑、一次撤销、保存和重开。直接在正文画板上画的原入口继续可用。

「主动关怀」开启后，每个本地自然日首次主动学习最多提示一次，忙于输入法、书写、保存或模型回复时保持安静。可跳过；选择「我准备好了」后直接继续学习。侧栏默认只有普通对话输入框，历史和设置收在右上角「更多」中。需要隐私时，选择「更多 → 不保存的对话」，才会打开独立小窗口。这个小窗口的原始对话只在内存中，关闭后清空，不写入普通聊天或学习画像，也不带入当前页面或普通聊天上下文。普通对话的历史保存仍遵循原设置，没有因界面简化而改变。

私有摘要必须由用户明确填写并确认，默认保留7天，可在设置中调整为1–30天；会话内可查看、删除或重新确认期限。桌面系统加密不可用时只提供临时会话。摘要存于应用私有目录，独立于 Vault、画板截图和常规发布/备份文件；模型服务商自身的数据政策仍适用。OpenCode 的恢复历史不能保证此会话不落盘，因此临时支持发送目前只支持用户已配置的 Direct API，不会自动替换连接。

「学习专家核对」开启后提供核对解释、检查数学图、补充资料三个入口。Codex 在独立临时会话中产生意见，Tutor 汇总证据、建议与不确定性。只有本次材料和选定图形会被发送；关怀内容、完整聊天和学习画像不传给专家。当前补充资料入口不具备联网检索，不把建议书目说成已经查证。专家失败、材料变动、取消或格式不完整均不算校核通过，也不会自动改学生记录。

## 数据与回退

- 历史画板保留 v5、原墨 ID 和角色版本；新记录在 `memoryRoot/learning/v1/episodes/`，专家记录在同级 `expert-reviews/`。
- 串行写入，保留 `.previous`；外部修订冲突保留候选，不覆盖双方内容。
- 源码基线与运行基线分别封存。安装事务会等待保存完成并在任务忙时拒绝安装，停用旧插件后暂存、校验、切换、重载健康检查。
- 默认回退只更换程序并关闭本轮三个开关；保留当前密钥、模型、批注、画作和新学习记录。旧版本暂不可见的新记录，在重新升级后可以读取。
- 运行基线包含私人配置与学习文件，只放本机私有备份，不能发到 Git 或发布目录。

安装：在任务空闲时，从本仓库运行（将路径替换为实际库和解压后的插件目录）：

```sh
node scripts/install-dev-plugin.mjs --vault /absolute/vault --source /absolute/release/annotation-tutor-lite
```

安装输出 `backup` 路径须保留。恢复命令不依赖新插件能够启动：

```sh
node scripts/install-dev-plugin.mjs --vault /absolute/vault --rollback /absolute/private/installation-backup
```

Obsidian 无法运行时，先退出 Obsidian，然后在同一命令增加 `--offline`，完成文件恢复后启动。不要在 Obsidian 运行时用离线模式替换程序。恢复工具包仅依赖 Node 22.13+；在线安装还需要本机 Obsidian CLI。安装目录中的未知文件和用户资产不作为程序垃圾删除。

每个版本与构建编号分别封存于 `dist/milestones/`，含哈希清单。P0–P3 验收范围见 [本轮验证记录](qa/learning-upgrade-20260926/report.md)。旧 `docs/tutor-upgrade-status.md` 描述0.3.0里程碑，不能当作本轮所有能力已经通过的证明。

## 支持边界与评测

借鉴 [MentalHealthBench 的评测方向](https://openai.com/index/introducing-mentalhealthbench/)，使用自行编写的中文成人合成案例检查倾听、持续困扰、风险回应、记忆纠正与依赖表达。尚未核实其数据下载和许可证，本轮没有导入其数据。

这不是心理诊断、学生心理评分或治疗服务。模型回应存在不稳定性；单轮样例通过不等于长期陪伴有效，更不代表临床或未成年人审查通过。未成年人、专业心理审查、长期效果、Android真机、远程多Agent与复杂人物的既有未通过项仍保持未通过。

0.4.3 只简化入口、文案和标题栏，不删除私有摘要、不改变学习与专家授权。新增体验评估见 [简化后评估](qa/simple-entry-20260926/report.md)。
