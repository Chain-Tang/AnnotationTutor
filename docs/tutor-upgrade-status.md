## 本轮验证暴露并修复的问题

- Obsidian 不支持插件入口中的相对 `require`：改为单文件内惰性初始化；移动分支初始化测试会拒绝任何桌面依赖。
- Portable MCP 清单缺少必需的 `$schema`，Skills 可见但工具未加载：生成器修复，同时保留兼容清单。
- A2A 完成/订阅竞态、并发重发、过早关闭取消连接；重连只查询已知任务，不盲目重发。
- 大场景提交已成功却可能因回传整场景过大报错：提交改为小回执，场景和矢量节点分页读取。
- 同一任务的目标 ID 相同却可换基准修订；畸形持久权限中的真值字符串；撤销配对后归属缓存残留；客户端断开后配对弹窗未取消。
- 对称笔触两次撤销和随机种子负数；活动笔触无视图层/透明锁定/擦除；转写问答正文使用了错误字段。
- 移动锚点把可变正文误作身份、缺少历史角色；日志重启覆盖旧索引；导出静默遗漏依赖资源。
