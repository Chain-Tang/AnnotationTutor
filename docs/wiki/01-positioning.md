# 01 · 产品定位与目标受众

## 一句话定位

**Annotation Tutor Lite** 是一个为 Obsidian 桌面端打造的学习插件：把原文高亮、纸感便签与 AI 辅助学习，连成属于你自己的 Markdown 记忆。

产品口号（可直接引用）：

> 读到重要的地方，留下自己的理解。

## 它解决什么问题

学习和阅读中常见三件头疼事，这个产品逐一给出答案：

| 痛点 | 产品的回答 |
| --- | --- |
| 理解散落在另一个窗口/软件里，离开原文就断了上下文 | 批注以高亮 + 便签的形式**留在原文旁边**，点击高亮随时重新打开 |
| 批注只是收藏，读完就忘，无法回顾 | AI 点评 → 提炼记忆单元 → SM-2 间隔重复 → 学习笔记本，形成**可反复调用的理解** |
| 笔记被平台/数据库锁死，迁移困难 | **文件式数据所有权**：一切是 Vault 里的普通 Markdown，索引只是可重建的缓存 |

## 核心理念（叙事基调）

1. **像便签一样自然，而不是又一个工具面板**——静止时以文字为主，操作按钮鼠标移入才显示。
2. **理解留在原文旁边**——高亮与便签通过块 ID 锚定，编辑原文不丢失关联。
3. **本地优先，数据属于你**——保存批注不需要 AI，不需要注册账号；AI 引擎由用户自己配置。
4. **从一次阅读，到可以反复调用的理解**——学习闭环：批注 → 点评 → 记忆 → 复习。

## 讲给谁听（目标受众画像）

按内容适配度排序：

- **论文/文献重度阅读者**：研究生、青年学者。痛点是 PDF 高亮与笔记割裂、读完记不住。PDF 批注不改写原始文件，是强卖点。
- **Obsidian / 本地知识管理用户**：关心数据所有权、Markdown 纯净性、无云端锁定。
- **外语学习者与深度阅读爱好者**：行内释义、整篇预翻译、点击原文回看批注。
- **考试/考证自学者**：记忆单元 + SM-2 间隔重复 + 弱项练习题生成。
- **手写/绘图爱好者（画板方向）**：Tutor Studio 灵感画板、七类笔刷、AI 对话画图、数学函数图。

## 它「不是」什么（避免误解）

- 不是云端笔记服务——没有任何服务器，不上传笔记。
- 不是自带模型的 AI 应用——插件不附赠模型服务，需要用户配置 Direct API 或 OpenCode。
- 不是 Anki——记忆单元是 Markdown 文件，复习由插件调度，但没有闪卡生态。
- 不是移动端产品——当前桌面专属（macOS/Windows/Linux），Pad 手写属于设计规划。
