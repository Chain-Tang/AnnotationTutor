# 03 · 卖点与传播叙事

## 差异化卖点（按传播力排序）

### 1. 「理解留在原文旁边」

竞品做法：高亮在阅读器里、笔记在另一个 App 里、复习在第三个软件里。本产品把三者连成一条 Markdown 文件链。这是最适合作为内容**主轴**的叙事。

可用表达：
- 「你的高亮不再是坟墓——点一下就能重新打开当时的想法。」
- 「读完就忘，不是你笨，是你的批注没有被安排复习。」

### 2. 「批注保存在 PDF 之外，不改原始文件」

对论文党是强痛点：很多 PDF 标注工具会污染/改写原文件，而这个产品的高亮层独立于 PDF，原文件保持干净、可继续分享。

### 3. 「全部是普通文件，没有数据库，没有账号」

对 Obsidian / 本地优先社区是最强共鸣点：
- 批注、记忆、场景、画像、笔记本 = 纯 Markdown，可直接打开、编辑、迁移。
- 索引只是可重建的缓存；删了缓存也不丢任何东西。
- 保存批注不需要 AI、不需要联网。

可用表达：「十年后你的笔记还能打开——因为它只是 .md 文件。」

### 4. 「AI 点评你的理解，而不是替你写笔记」

定位差异：不是 AI 生成内容工具，而是 AI 检查你真正理解了没有（correct / partially / incorrect），并沉淀为可复习的记忆。契合「主动回忆」「精细加工」等学习科学话术。

### 5. 「SM-2 间隔重复 + 有据可依的记忆」

与 Anki 类比降低解释成本：「Anki 式的复习调度，但每张卡片是你自己的批注长出来的，且带证据链。」强项/弱项总结来自真实复习表现（reps/lapses），不是模型猜测——这是一个少有人讲的技术细节卖点。

### 6. 「和导师对话，它直接在画板上画图」（画板方向）

适合短视频演示的「哇点」：
- 流式对话逐步画图，Tutor 边回复边把图形画出来。
- 「画 sin(x)/x 在 0 附近的极限图，标出空心点」→ 自动识别意图、宿主精确计算、可编辑、整轮撤销。
- 七类笔刷真实算法预览可分享；导出 SVG/OpenRaster 对创作者友好。

### 7. 「外部智能体可读的学习记忆」

面向 AI 玩家人群：`AGENTS.md` 文件协议让 Claude Code / Codex 等外部代理直接消费你的学习记忆——「你的笔记库自带一层智能体 API，只是它用 Markdown 写成」。

## 建议的标题/钩子方向

> 以下为灵感示例，发布前请按 06 篇的用词规范自查（不要夸大为「完全离线」「AI 私教」等）。

- 「我在 Obsidian 里造了一个会追问我的读书便签」
- 「论文高亮完就忘？我把批注变成了复习计划」
- 「不改 PDF 原文件的标注方式，才敢用在导师发的稿子上」
- 「你的笔记不需要数据库」
- 「让 AI 检查我读懂了没有，而不是替我写读后感」
