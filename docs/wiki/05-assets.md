## 必拍截图/录屏清单

按内容完成度排序，标注了每张素材要证明的功能点：

1. 选中文字 → 快捷键呼出批注弹窗（证明：核心动作一步到位）
2. 页边可拖动便签 + 鼠标移入才显示按钮（证明：「写作优先」交互；建议录屏，静图无法体现 hover 显隐）
3. 表格单元格批注（证明：重复文字也能按出现顺序锚定）
4. PDF 选区批注 → 点击高亮重新打开 → 页码回链（证明：PDF 与 Markdown 共用一套高亮语言）
5. 便签的 Agent Review 区段（证明：AI 判对了/部分对/错了，且有依据）
6. `Agent Memory/` 目录树 + 一个批注文件的 frontmatter（证明：纯文件数据所有权）
7. 「Review due cells」复习界面与 Again/Hard/Good/Easy 评分（证明：间隔重复闭环）
8. 学习笔记本 Notebook.md 及其双层回链（证明：笔记本→批注→原文两次点击可达）
9. 灵感画板：左侧竖栏画七类笔刷、右侧对话流式逐步画图（证明：Tutor 边回复边画）
10. 数学作图：「画 sin(x)/x 在 0 附近的极限图，标出空心点」完整过程（证明：意图识别 + 宿主计算 + 整轮可撤销）
11. 导出面板：PNG/JPEG/WebP/SVG/PDF/.ora/.tutorboard 列表（证明：创作者友好的导出）
12. 翻译：`Alt+T` 行内释义与整篇预翻译（证明：沉浸式阅读）

## 视觉规范

- **皮肤**：优先用默认/简洁皮肤录制教学向素材；纸张、便利贴、叶片皮肤适合氛围向封面。
- **高亮颜色**：使用设置中的统一颜色变量展示，PDF 与 Markdown 应呈现同一种高亮语言——同屏对比时不要分别调成不同色。
- **字体**：正文演示避免使用画板手写字体（那是手绘场景素材）。
- **按钮显隐**：截图前先把鼠标悬停到卡片上让按钮显现，否则读者看不到操作入口。
- **界面语言**：面向国内受众用简体中文截图；发布到海外平台请切换 English，四种语言都是可讲的卖点。

## 截图隐私与安全红线

- 绝不入镜：API 密钥输入框、Vault 绝对路径、真实论文全文、他人笔记内容。
- 演示用文档统一用自造或公开许可材料。
- 分享画板作品的素材（表情/共创）独立于 Tutor 角色——演示时说明清楚来源，不要暗示内置角色自带这些素材。
