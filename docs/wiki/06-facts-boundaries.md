## 当前边界（可如实写进内容的「不足」清单）

引用自 README「当前边界」，做诚实评测时建议原样传达：

- PDF 依赖阅读器文字层；扫描件需先 OCR。批注不导出为 PDF 内嵌评论。
- PDF 的「粗体」以更重的下划线强调，不修改原文字形。
- 表格重复文字按出现顺序匹配，尚无完整行列语义身份。
- C66 桌面代码已实现 Pointer Events、压感/倾斜与十种笔刷类型；完整桌面笔感/负载及 Android 真机门禁未完成。
- 水彩笔刷是确定性多层透明 dab 与湿边模拟，**不是真实流体混色**。
- 当前不包含 PSD、CMYK/HDR、完整蒙版、滤镜栈、多人实时协作。
- 数学作图的数值检查不是数学证明；拖动对象不会自动重算数学关系。
- 学习闭环、主动关怀和专家核对等入口默认关闭（见各版本说明）。

## 版本与平台事实口径

- **版本号**：以安装时 `manifest.json` 与 GitHub Releases 为准；源码可能领先于发行版。不要长期写死某个版本号，文档/视频里给「如何查看当前版本」比给数字更耐用。
- **环境要求**：Obsidian 1.12.4+，桌面端（macOS/Windows/Linux）。普通用户**不需要安装 Node.js**；从源码构建才需要 Node 22.13+ 与 pnpm 10。
- **安装口径**：手动安装需同版本的 `main.js`、`manifest.json`、`styles.css` 与完整 `assets/fonts/` 目录；**仅复制三个常规文件不足以安装画板手写字体**。BRAT 只安装已发行的兼容版本。
- **复制新文件 ≠ 已重载插件**：演示教程里要提醒重载 Obsidian，否则读者会以为功能失效。

## 隐私与安全表述规范

- 密钥保存位置：**C66 开发候选**使用系统加密的 Vault 外凭据存储，配置保留引用；加密不可用时不能宣称安全持久化。历史安装版本需单独核对，不能把候选迁移结果扩大到所有用户。
- 必须提醒读者：**不要把插件配置和密钥上传到公共仓库**。
- 服务商的隐私政策、数据保留、额度与费用独立于本插件——讲 AI 功能时带一句。
- 公开分享画板作品默认移除源文档路径、识别服务信息和隐藏图层（这是可讲的隐私设计亮点）。
- `preferences.md` 默认禁止代理写入；记忆写入可切确认模式，所有变更先入 proposals 队列——适合回应「AI 会不会乱改我笔记」的质疑。
