# Annotation Tutor Lite — 内容创作者 Wiki

本目录是为**外部内容创作者**（博主、UP 主、视频作者、公众号/小红书创作者）准备的资料库。
目标是帮助你基于真实的产品能力，产出准确、有吸引力、不踩合规红线的内容。

> 事实来源：本 wiki 与仓库内 `README.zh-CN.md`、`docs/guide.md`、`CHANGELOG.md`、`manifest.json` 保持一致。
> 发布任何内容前，请核对 `manifest.json` 中的版本号与 [GitHub Releases](https://github.com/Chain-Tang/AnnotationTutor/releases) 的最新发行版——源码版本可能领先于已发行版本。

> 2026-10-12 核对：开发候选为 **0.5.4 / C66**，测试库已安装，日常 Documents 库仍为 0.5.3。完整商业、自然学习交互及成人支持质量门未通过。功能已写入代码不等于验收完成；传播前以 [最新实现核对](../qa/implementation-status-20261012/report.md) 和对应逐项证据为准。

## 30 秒速览

- **是什么**：Obsidian 桌面端插件，把「原文高亮 + 自己的理解 + AI 点评」沉淀为纯 Markdown 的学习记忆。
- **独有气质**：无需独立数据库、不强制云端账号；批注保存在 PDF 之外；数据全部是可读、可改、可迁移的文件。
- **一句话**：读到重要的地方，留下自己的理解——并且这些理解能被 AI 导师读懂、被未来的你找回。
- **协议**：MIT，© Chain。仓库：`Chain-Tang/AnnotationTutor`。

## 使用约定

- 引用产品能力时，注明你所测试的**插件版本 + Obsidian 版本**。
- 涉及 AI 能力的表述，遵守 [06 · 事实边界与合规表述](06-facts-boundaries.md) 的用词规范。
- 若发现本 wiki 与代码现状不符，以仓库为准，并欢迎提 issue 或 PR 修正。
