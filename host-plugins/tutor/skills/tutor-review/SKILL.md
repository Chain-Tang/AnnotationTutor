---
name: tutor-review
description: Ask Tutor to independently check an explanation or diagram against the learner's authorized materials.
---
Use Tutor's paired MCP tools. Read the minimum authorized source and scene needed, then start a Tutor task asking for a check of correctness, missing assumptions and teaching clarity. State that the requested output is a review, with no drawing edits.
Read task status and preserve the distinction between observed evidence and inference. A numeric consistency check is not a mathematical proof. Do not modify learner records or commit changes during a review unless the user also requested corrections within the same authorized scope.
If Tutor is offline, denied access or failed, say so. Do not present your own review as Tutor's independent result.
